# Cards

Cards — одностраничный настольный веб-помощник для учёта карт в онлайн-«Дураке». Пользователь отмечает разыгранные карты в течение хода и подтверждает, ушли они в бито или были взяты игроком.

Приложение не реализует правила игры, игроков, руки и колоду добора. Все данные остаются в текущем браузере.

## Возможности

- отображение всех 36 карт от шестёрки до туза;
- выбор козырной масти с автоматическим перемещением её столбца вправо;
- предварительный выбор не более 12 карт за один ход;
- два исхода хода: «Конец хода» переносит карты в бито, «Взял» возвращает их в игру;
- автоматическое начало хода при первом выборе карты;
- безопасный сброс новой партии;
- восстановление подтверждённых карт, козыря и незавершённого хода после обновления страницы;
- управление мышью и клавиатурой.

## Стек

- React 19 и TypeScript;
- Vite;
- CSS Modules;
- Vitest, jsdom и React Testing Library;
- `localStorage` для локального состояния партии.

## Требования

- Node.js 20.19+, 22.12+ или более новая поддерживаемая версия;
- npm 10+;
- современный настольный браузер.

## Установка и локальный запуск

```bash
npm install
npm run dev
```

После запуска откройте адрес, который Vite выведет в терминале.

## Как пользоваться

1. Выберите козырную масть.
2. Нажмите «Начало хода» или сразу нажмите доступную карту — во втором случае ход начнётся автоматически.
3. Выберите до 12 разыгранных карт. Повторное нажатие снимает предварительный выбор.
4. Нажмите одну из кнопок исхода:
   - «Конец хода» — выбранные карты окончательно переходят в бито;
   - «Взял» — выбранные карты возвращаются в игру, поскольку они ушли игроку в руку.
5. Для полного сброса нажмите «Новая партия». При наличии выбранных карт приложение запросит подтверждение.

## Хранение данных

Текущая партия автоматически сохраняется в `localStorage` под версионированным ключом. После обновления или повторного открытия страницы восстанавливаются карты «в бито», выбранный козырь и незавершённый ход.

Данные не отправляются на сервер и не синхронизируются между браузерами или устройствами. Повреждённое или недоступное хранилище не мешает запуску чистой партии.

## Размещение на статическом хостинге

1. Установите зависимости и соберите проект:

   ```bash
   npm ci
   npm run build
   ```

2. Опубликуйте содержимое каталога `dist` на любом статическом хостинге.
3. При размещении в корне домена дополнительная настройка `base` не нужна.
4. При размещении в подпути передайте Vite публичный путь при сборке, например:

   ```bash
   npm run build -- --base=/cards/
   ```

Проект не привязан к конкретной площадке. Для SPA-хостинга следует настроить выдачу `index.html` как fallback, если площадка не делает это автоматически.

## Ограничения MVP

- нет регистрации и синхронизации между устройствами;
- нет игроков, рук, колоды добора и проверки правил «Дурака»;
- нет автоматического распознавания карт на другом сайте;
- нет статистики нескольких партий;
- мобильный интерфейс не является отдельным продуктом.
