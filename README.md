# Cards

Cards — одностраничный веб-помощник для учёта карт, вышедших из игры в онлайн-«Дураке». Проект не реализует правила игры: он помогает видеть, какие карты ещё не были отмечены.

## Требования

- Node.js 20.19+ или 22.12+
- npm 10+
- современный браузер для настольного компьютера

## Установка

```bash
npm install
```

## Запуск

Запустить локальный сервер разработки:

```bash
npm run dev
```

После запуска открыть адрес, указанный Vite в терминале.

## Управление партией

- Выбор козырной масти переставляет соответствующий столбец вправо и не снимает отметки с карт.
- Нажмите «Начало хода» и выберите до 12 разыгранных карт. Если нажать карту до начала хода, приложение начнёт ход автоматически.
- Повторное нажатие снимает предварительный выбор карты.
- «Конец хода» окончательно отправляет выбранные карты в бито. «Взял» завершает ход и возвращает выбранные карты в игру, поскольку они ушли игроку в руку.
- Кнопка «Новая партия» сбрасывает подтверждённые и предварительно выбранные карты, завершает ход и возвращает козырь к пикам. Если карты уже выбраны или отмечены «в бито», приложение сначала запрашивает подтверждение.

## Хранение данных

Текущая партия автоматически сохраняется только в `localStorage` текущего браузера. После обновления или повторного открытия страницы восстанавливаются отмеченные карты, выбранный козырь и незавершённый ход. Данные не отправляются на сервер и не синхронизируются между браузерами или устройствами.

## Проверка и сборка

Проверить исходный код линтером:

```bash
npm run lint
```

Запустить тесты:

```bash
npm run test -- --run
```

Создать production-сборку в каталоге `dist`:

```bash
npm run build
```

Локально просмотреть production-сборку:

```bash
npm run preview
```
