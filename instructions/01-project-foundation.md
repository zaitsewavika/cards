# Задача 01. Подготовить основу проекта

## Цель

Превратить стартовый шаблон Vite в чистую и предсказуемую основу проекта Cards.

## Зависимости

Нет. Это первая задача.

## Что сделать

1. Установить зависимости проекта через `npm install`.
2. Удалить демонстрационные изображения, счётчик и стили Vite/React.
3. Создать каталоги, описанные в `00-architecture.md`; пустые каталоги создавать только тогда, когда в них появляется первый файл.
4. Перенести корневой компонент в `src/app/App.tsx`.
5. Создать `src/styles/global.css` и подключить его из `src/main.tsx`.
6. Задать базовые стили: `box-sizing: border-box`, системный шрифт, нейтральный фон, минимальную высоту страницы и наследование шрифта кнопками.
7. Обновить заголовок и метаописание в `index.html`.
8. Проверить строгие настройки TypeScript. Не отключать правила ради подавления ошибок.
9. Сохранить рабочие команды `dev`, `build`, `lint`, `preview`.
10. Обновить корневой `README.md`: назначение проекта, требования, установка, запуск и сборка.

## Ожидаемые основные файлы

- `src/main.tsx`
- `src/app/App.tsx`
- `src/app/App.module.css`
- `src/styles/global.css`
- `index.html`
- `README.md`

## Ограничения

- Не реализовывать карты и игровое состояние в этой задаче.
- Не устанавливать UI-фреймворк, роутер или библиотеку состояния.
- Не оставлять неиспользуемые ассеты стартового шаблона.

## Критерии приёмки

- `npm run dev` показывает чистую страницу Cards без демо Vite.
- В консоли браузера нет ошибок.
- Нет неиспользуемых импортов и ассетов.
- `npm run lint` и `npm run build` проходят успешно.

## Проверка

```bash
npm run lint
npm run build
```
