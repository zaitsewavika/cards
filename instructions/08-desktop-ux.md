# Задача 08. Отполировать интерфейс для ПК

## Цель

Сделать приложение быстрым и удобным в режиме соседнего окна рядом с онлайн-игрой.

## Зависимости

- Выполнены задачи 01–07.

## Что сделать

1. Проверить интерфейс на ширинах примерно 1920, 1440, 1280, 1024 и 800 px.
2. Оптимизировать размеры карт и отступы через CSS custom properties.
3. Не допускать вертикального растягивания панели управления.
4. Сделать высоту поля предсказуемой; по возможности все девять строк должны быть доступны без длинной прокрутки.
5. Добавить компактную инструкцию: «Нажмите карту, когда она ушла в бито. Повторное нажатие вернёт её».
6. Сделать курсор и hover-состояние очевидными.
7. Запретить выделение текста внутри карт при быстрых нажатиях, не нарушая выделение обычного текста страницы.
8. Проверить контраст красных мастей, текста, рамок и состояния disabled.
9. Проверить полную навигацию клавиатурой и порядок фокуса.
10. Добавить обработку `prefers-reduced-motion`.
11. Убедиться, что состояние «в бито» видно при дальтонизме и на некачественном мониторе.
12. Проверить, что переключение козыря не вызывает неприятного скачка размеров сетки.

## Не делать

- Не добавлять мобильную навигацию как отдельный интерфейс.
- Не добавлять сложные анимации перелёта карт.
- Не использовать фоновые изображения, ухудшающие контраст.
- Не оптимизировать через `React.memo` без измеренной причины.

## Критерии приёмки

- Приложением удобно пользоваться в окне, занимающем часть экрана.
- Все основные действия требуют одного нажатия, кроме подтверждённого сброса.
- Пользователь мгновенно различает доступные и выбывшие карты.
- Козырный столбец всегда визуально понятен.
- Нет наложений, обрезанного текста и неожиданной прокрутки по горизонтали на согласованных ширинах.
- Lint и build проходят.
