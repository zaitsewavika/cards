# Инструкции проекта Cards

Архитектурные требования проекта зафиксированы в [00-architecture.md](./00-architecture.md). Нумерованные задачи перенесены в GitHub Issues и больше не хранятся отдельными Markdown-файлами в репозитории.

## Выполненные этапы

- Задача 01 — подготовлена основа проекта и инструменты качества.
- Задача 02 — реализована типизированная модель колоды из 36 карт.
- Задача 03 — реализованы состояние партии, редьюсер и селекторы.

Перед началом задачи необходимо полностью прочитать соответствующий issue и проверить перечисленные в нём зависимости. Правила работы с ветками, PR и документацией находятся в корневом `AGENTS.md`.

## Основные команды проверки

После каждой задачи проект должен проходить:

```bash
npm run lint
npm run build
```

После подключения тестов также выполнять:

```bash
npm run test -- --run
```
