# Инструкции проекта Cards

Этот каталог содержит архитектуру и последовательный план разработки веб-помощника для карточной игры «Дурак».

## Порядок работы

1. Сначала прочитать [00-architecture.md](./00-architecture.md).
2. Затем выполнять задачи строго по порядку — от `01` до `10`.
3. Один файл описывает одну законченную задачу, которую можно передать отдельному агенту.
4. Перед началом задачи агент должен проверить результаты всех указанных зависимостей.
5. Задача считается завершённой только после выполнения критериев приёмки и команд проверки.

## Список задач

- `01-project-foundation.md` — подготовка чистого проекта и инструментов качества.
- `02-card-domain-model.md` — типизированная модель колоды из 36 карт.
- `03-game-state.md` — состояние партии, reducer и отмена действий.
- `04-card-component.md` — визуально узнаваемая интерактивная карта.
- `05-board-layout.md` — таблица номиналов и перенос козырной масти вправо.
- `06-game-controls.md` — статус партии, отмена и безопасный сброс.
- `07-persistence.md` — восстановление партии после обновления страницы.
- `08-desktop-ux.md` — финальная полировка интерфейса для ПК.
- `09-testing.md` — модульные и компонентные тесты.
- `10-final-qa-and-release.md` — итоговая проверка и подготовка к публикации.

## Основная команда проверки

После каждой задачи проект должен как минимум проходить:

```bash
npm run lint
npm run build
```

После подключения тестов также выполнять:

```bash
npm run test -- --run
```
