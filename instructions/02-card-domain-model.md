# Задача 02. Реализовать модель колоды

## Цель

Создать типобезопасный источник данных для всех 36 карт без ручного дублирования объектов.

## Зависимости

- Выполнена задача 01.

## Что сделать

1. Создать `src/game/types.ts` с типами `Suit`, `Rank`, `CardId` и `Card`.
2. Создать `src/game/cards.ts`.
3. Объявить константы `SUITS` и `RANKS` в зафиксированном порядке.
4. Добавить словари символов мастей и русских подписей достоинств.
5. Реализовать чистую функцию генерации колоды как `RANKS × SUITS`.
6. Экспортировать неизменяемый массив `CARDS` из 36 элементов.
7. Добавить функцию или селектор получения карты по `CardId`, если она действительно используется последующими компонентами.
8. Не включать UI-состояние `discarded` в объект карты: это состояние конкретной партии, а не свойство карты.

## Инварианты

- В колоде ровно 36 карт.
- Каждый `CardId` уникален и имеет формат `${suit}-${rank}`.
- Все четыре масти представлены для каждого достоинства.
- Порядок `RANKS`: 6, 7, 8, 9, 10, валет, дама, король, туз.
- Красными считаются только `diamonds` и `hearts`.

## Ожидаемые файлы

- `src/game/types.ts`
- `src/game/cards.ts`
- позднее: `src/game/cards.test.ts`

## Критерии приёмки

- TypeScript не допускает произвольную строку вместо масти, достоинства или `CardId`.
- Колода строится программно, а не списком из 36 вручную написанных объектов.
- Доменные файлы не импортируют React и CSS.
- `npm run lint` и `npm run build` проходят успешно.
