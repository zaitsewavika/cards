# Задача 05. Построить игровое поле и порядок козыря

## Цель

Вывести 36 карт в настольной таблице: девять строк по достоинствам и четыре столбца по мастям, с козырной мастью всегда справа.

## Зависимости

- Выполнены задачи 01–04.

## Что сделать

1. Создать `GameBoard` и его CSS Module.
2. Получать через props:
   - текущую козырную масть;
   - коллекцию `discardedIds`;
   - обработчик переключения карты.
3. Получить порядок мастей селектором `getOrderedSuits(trumpSuit)`.
4. Создать девять строк строго по массиву `RANKS`.
5. В каждой строке вывести четыре карты одного достоинства в вычисленном порядке мастей.
6. Не сортировать достоинства по локализованным строкам: источником порядка остаётся `RANKS`.
7. Добавить заголовки столбцов с символом и названием масти.
8. Над крайним правым столбцом явно написать «Козырь».
9. Визуально отделить козырный столбец фоном или вертикальной границей.
10. Применить CSS Grid так, чтобы все строки имели одинаковые ширины столбцов.
11. Рассчитать размер так, чтобы поле помещалось рядом с окном онлайн-игры при типичном разрешении ПК. При узком окне допустим горизонтальный скролл, но карты не должны превращаться в нечитаемые миниатюры.
12. Добавить строковые подписи достоинств только если они реально помогают ориентации и не дублируют карту чрезмерно.

## Инварианты раскладки

- Сверху вниз: 6, 7, 8, 9, 10, В, Д, К, Т.
- В каждой строке ровно четыре разные масти.
- Выбранная козырная масть всегда в последнем столбце.
- При смене козыря отмеченные карты остаются отмеченными.
- Перестановка выполняется только в представлении, идентификаторы карт не меняются.

## Критерии приёмки

- На странице одновременно видны все 36 карт на обычном ПК-мониторе либо требуется только минимальная прокрутка по высоте.
- Смена козыря немедленно переставляет столбцы.
- Порядок строк никогда не меняется.
- Нажатие любой карты вызывает корректный `CardId`.
- Нет дублирующихся или пропавших карт.
- Lint и build проходят.
